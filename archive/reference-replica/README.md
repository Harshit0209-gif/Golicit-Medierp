# Reference replica (archived)

The first version of this project: a pixel-faithful build of the original MedRecruit landing-page mock-up (`docs/case-study/01-reference-mockup.png`), matched to within ±3px at 1440px. It is kept for the case study's before/after comparison and is not compiled by the current app. Its `src/` used the same toolchain (React + Vite + TypeScript).
